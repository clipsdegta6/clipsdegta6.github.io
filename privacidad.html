Política de privacidad

Última actualización: 20 de noviembre de 2026.

Quién la usa

GTA Clipper solo la usan los administradores de nuestras propias cuentas. No tiene usuarios externos ni recoge datos de otras personas.

Qué datos usa

Con el permiso de cada plataforma (YouTube, Instagram y TikTok), la herramienta: (1) sube vídeos a nuestras cuentas, y (2) lee las estadísticas de nuestras propias publicaciones (visualizaciones, alcance, origen del tráfico) para saber qué funciona. Los permisos se guardan solo en el ordenador del administrador.

Qué no hacemos

No vendemos ni compartimos datos con nadie, no hacemos publicidad con ellos y no accedemos a datos de otros usuarios.

Uso de los servicios de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. GTA Clipper usa los servicios de la API de YouTube; consulta también los Términos del servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el permiso

Se puede retirar en cualquier momento desde la configuración de seguridad de cada cuenta (Google: myaccount.google.com/permissions; Instagram y TikTok: aplicaciones conectadas). Ver también Eliminación de datos.

English

GTA Clipper is used only by the administrators of our own accounts. With each platform's permission it uploads videos to our accounts and reads statistics of our own posts. Tokens are stored only on the administrator's computer. We do not sell or share any data and do not access other users' data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from each account's security settings.
